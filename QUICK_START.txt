PrintEase - Ultra Quick Setup
=============================

1. INSTALL PYTHON
   - Download: python.org/downloads
   - Install with "Add to PATH" checked

2. SETUP
   cd PrintEase
   python -m venv venv
   
   # Windows:
   venv\Scripts\activate
   
   # Mac/Linux:
   source venv/bin/activate
   
   pip install -r requirements.txt

3. CONFIGURE
   - Copy .env.example to .env
   - Edit .env with shop's UPI ID and name
   
4. SET DEFAULT PRINTER
   - Windows: Settings → Printers → Set default
   - Mac: System Settings → Printers → Set default

5. RUN
   python app.py
   
6. SHARE
   - Find computer's IP (ipconfig on Windows, ifconfig on Mac)
   - Students go to: http://YOUR_IP:5001
   - Staff go to: http://YOUR_IP:5001/staff

DONE! 🎉

Questions? Check SETUP_GUIDE.md for detailed instructions.
