QUICK START GUIDE
=================

1. SETUP
--------
- Install Python 3.11+
- Get Razorpay test keys from: https://dashboard.razorpay.com/
- Copy .env.example to .env
- Add your Razorpay credentials to .env

2. INSTALL
----------
python3 -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt

3. CONFIGURE
------------
Edit .env file:
RAZORPAY_KEY_ID=rzp_test_YOUR_KEY_ID
RAZORPAY_KEY_SECRET=YOUR_KEY_SECRET
SECRET_KEY=random-secret-key

4. RUN
------
python app.py

5. ACCESS
---------
Desktop: http://localhost:5001
Mobile: http://YOUR_IP:5001

6. TEST PAYMENT
---------------
Use Razorpay test credentials:
- UPI: success@razorpay
- Card: 4111 1111 1111 1111

7. FLOW
-------
Upload PDF → Select Settings → Pay via Razorpay → Auto Print → Done!
